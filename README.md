# 📱 FeedHub

O **FeedHub** é um projeto de interface simples e moderna inspirada em redes sociais como Instagram, voltado para o aprendizado de conceitos fundamentais do ReactJS. Ideal para quem está começando ou quer reforçar conhecimentos em componentes, props, estado e estilização com CSS Modules.

---

## 🚀 Tecnologias utilizadas

- **ReactJS**
- **JavaScript**
- **CSS Modules**
- **Vite**

---

## 💻 Demonstração

Acesse o projeto online: [FeedHub](https://marcelobueno25.github.io/feedhub.github)

## 📦 Como executar o projeto localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/marcelobueno25/feedhub.github

2. Acesse a pasta do projeto:
      ```bash
      cd feedhub.github

4. Instale as dependências:
   ```bash
    npm install

6. Inicie o servidor de desenvolvimento:
   ```bash
    npm run dev

8. Acesse no navegador:
   ```bash
   http://localhost:5173
